TROX · ДЛЯ АГРЕССИВНЫХ СРЕД

TROX CAK

Пластиковый круглый шумоглушитель для вытяжных систем с загрязнённым или агрессивным воздухом.

Назначение
Шумоглушение в пластиковых воздуховодах вытяжных систем с агрессивными средами.
Материал
Пластиковый корпус для специальных вытяжных применений.
Совместимость
Применяется совместно с профильными VAV/CAV устройствами для агрессивных сред.
Подбор
По расходу, акустике, сопротивлению и химической совместимости среды.
CAK — важная позиция для лабораторной и химстойкой вытяжной вентиляции.
