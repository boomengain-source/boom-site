ЧИСТЫЕ ПОМЕЩЕНИЯ · TROX

HEPA/ULPA и терминальная фильтрация

Финишная фильтрация и воздухораспределение для фармацевтики, медицинских помещений, лабораторий, биотехнологий, микроэлектроники и других критических зон.

ПРОДУКТОВАЯ ЛИНЕЙКА

Ключевые решения TROX для чистых помещений

Подбор по классу чистоты, типу потолка или стены, способу подключения, требованиям к валидации и классу фильтра.

TFP

Фармацевтический терминальный фильтр для особо чувствительных зон и удобной валидации.

  • Классы чистоты ISO 5–8
  • Номинальные размеры 400 / 500 / 600 / 625 мм
  • Fluid seal, Mini Pleat
  • VDI 6022
  • Потолочный монтаж
ПодробнееTROX ↗

TFC

Универсальный потолочный терминальный фильтр для медицины, биологии, фармы и чувствительных технических зон.

  • Классы чистоты ISO 5–8
  • Номинальные размеры 400–825 мм
  • Flat / continuous / gel seal
  • VDI 6022
  • Герметичность L1 / Class D
ПодробнееTROX ↗

TFM

Модульные потолочные фильтрующие секции, которые можно объединять в крупные потолочные поля.

  • Классы чистоты ISO 5–8
  • 600 × 600 / 900 / 1200 мм
  • Flat или fluid seal
  • Контроль перепада давления
  • VDI 6022
ПодробнееTROX ↗

TFW

Настенный терминальный фильтр для чистых помещений с доступом со стороны чистой зоны.

  • Классы чистоты ISO 5–8
  • Настенный монтаж
  • Контроль перепада и герметичности
  • VDI 6022
  • Решётка X-GRILLE modular
ПодробнееTROX ↗

MFPCR

Mini Pleat фильтрующие панели для чистых помещений — от высокоэффективной HEPA до ULPA фильтрации.

  • H13 / H14 / U15 / U16
  • DIN EN 1822
  • DIN EN ISO 29463
  • VDI 6022
  • Scan test для высоких классов
